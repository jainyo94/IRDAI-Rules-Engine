⚖️ IRDAI Master Circular Rules Engine (2024)
Developed by Juriscode Labs

Overview
This project demonstrates the translation of complex legal text into executable machine logic. Using the IRDAI Master Circular on Health Insurance (May 2024), we have extracted 21+ critical decision rules into JSON and CSV formats.

Why this matters
Compliance in the insurance sector is often slowed by manual interpretation of PDFs. By converting law into JSON Schema, we enable:

Automated Compliance: Plug-and-play logic for claim settlement systems.

Real-time Auditing: Immediate flagging of regulatory violations.

Legal-Tech Integration: Bridging the gap between the Regulator and the Developer.

Tech Stack
LLM: Groq/Llama-3 for logic extraction.

Data: Python (fitz, pandas) for PDF parsing and structuring.
